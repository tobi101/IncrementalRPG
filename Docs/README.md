# Настройки IncrementalRPG: руководство для геймдизайнера и аниматора

Состояние проекта на 18 сентября 2026 года. Документация описывает текущие скрипты, конфиги, сцены и префабы, включая разделённый урон атак, отдельный интервал бочек и подключённую ветку частоты спавна. Это справочник реализации, а не предложение нового баланса и не пересказ ГДД.

## Документы

- [Геймплей и баланс](/Users/admin/IncrementalRPG/Docs/GameplaySettings.ru.md): все характеристики дерева, атаки, существа, бочки, спавн, уровни, генерация, осколки, предметы, инвентарь и награды.
- [Анимации, интерфейс и звук](/Users/admin/IncrementalRPG/Docs/PresentationSettings.ru.md): дамаг-зона, существа и смерть, лава, сундук, шторка, дерево, хаб, меню, эффекты, текст, локализация и аудио.
- [Каталог полей и мест настройки](/Users/admin/IncrementalRPG/Docs/SettingsCatalog.ru.md): точные имена полей, файлы, объекты Hierarchy, сохранённые значения основных настроек, размещённые ноды и используемые Spine-ресурсы.

## Как пользоваться

1. Найдите нужную фичу в одном из двух руководств.
2. Откройте указанный asset в Project или сцену и объект в Hierarchy. Компонент указан рядом.
3. Найдите поле в Inspector. Например, `_spinSpeed` отображается как **Spin Speed**, `baseRadius` — как **Base Radius**. В документах приведены точные имена полей для однозначного поиска.
4. Меняйте настройки вне Play Mode. Изменения компонентов сцены во время Play обычно не сохраняются; ScriptableObject-ассеты могут сохранять изменения и во время игры.
5. Сохраните asset/сцену. Для параметров, которые считываются при старте уровня или создании объекта, начните новый заход/перезайдите на уровень.

**База и прокачка — разные места.** База урона хранится в конфиге атаки, прибавка от покупки — в ноде. Частота спавна и размеры карты пересчитываются при применении уровня. Изменение размера анимации не заменяет изменение игрового радиуса.

**Префаб и экземпляр — разные области изменения.** Изменение префаба распространяется на его экземпляры, кроме полей с Overrides. У существ есть базовый `Creature.prefab` и варианты для конкретных видов. Для одного вида редактируйте его вариант. Для настройки в сцене сначала проверьте, нет ли локального Override.

**Числа.** Время — секунды, если не сказано иначе. Координаты мира отличаются от единиц UI Canvas. Для долевых бонусов `0.1` означает 10%; для абсолютной прибавки `10` означает десять единиц. Поля `BigDouble` принимают обычные числа и запись вида `1e6`; HP, урон, золото и награды нормализуются до целых там, где это делает текущий код.

**Сохранения.** Купленные уровни, ресурсы и предметы не равны начальному состоянию конфигов. Поля `id`, `itemId`, `dungeonId`, `levelId` связывают данные и прогресс; для нового контента задавайте отдельные идентификаторы. Изменение идентификатора существующего контента — вопрос совместимости сохранений.

## Быстрый поиск

| Что хочется изменить | Где искать |
|---|---|
| Урон, интервалы трёх атак, радиус зоны | `DamageZoneConfig` + соответствующий `StatType` в ноде |
| Цена/сила улучшения, зависимости, положение | `NodeDefinition` + `SkillTreeConfig.entries` |
| Частота врагов и бочек | `DungeonLevelConfig`, раздел Spawn |
| HP, награды и движение существа | `EntityConfig` нужного вида |
| Взрыв бочки | `BombExplosionConfig`; HP и вид бочки — её `EntityConfig` |
| Размер карты, жар, опыт до следующего уровня | `DungeonLevelConfig` |
| Тайлы, распределение поверхности, стены | `TilemapGenerationConfig` + `TilemapTileSet` |
| Скорость анимации существа/атаки | Spine-компонент в префабе; правила переопределения — в руководстве аниматора |
| Скорость лутбокс-ленты | `LootboxView` на `HUD/LevelTransitionCurtainView/RevealGroup/LootboxGroup` |
| Сила пяти зелий, процентная шкала и статус подключения | [Настройки зелий](/Users/admin/IncrementalRPG/Docs/GameplaySettings.ru.md#potion-test-settings); `ItemDefinition.effectValue` |
| Скорость движения шторки | `GameSceneInstaller → Level Transition Config` |
| Кривая движения шторки, задержка лампы | `LevelTransitionCurtainView` |
| Музыка, эффекты, громкость | `AudioManager` в `BootstrapScene` |
| Точный список мест использования | Каталог полей |

## Граница справочника

Охвачены собственные игровые конфиги и сериализованные компоненты проекта, используемые игровые Spine-ресурсы и точки настройки Unity/инвентарного плагина. Служебные ссылки вынесены в каталог. Демосцены сторонних пакетов, настройки сборки/платформы и внутренние параметры библиотек не являются настройками игровых фич и сюда не включены.

Если параметр существует в данных, но пока не используется игровой логикой, либо код перезаписывает его, это отмечено явно. Для таких случаев изменение значения в Inspector само по себе не добавляет функциональность. Пять зелий подключены к игровым расчётам, сохранению, наградам и локализованному HUD. Их тестовый баланс, формулы и правила применения описаны в разделе предметов.
